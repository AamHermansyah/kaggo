info:
  title: Kaggo Admin Portal API
  version: "1.1.0"
  description: |
    Admin-facing REST API: dashboard, users, vehicles (including
    onboarding), shipments, revenue, settings, and logistics-company
    management. Unlike the rider-facing backend, this uses real
    email/password login + JWT - see docs/admin-portal.md for why admin
    accounts are a completely separate model from riders' phone-only
    identity.

    There is no public registration endpoint - accounts are provisioned
    via `apps/admin-api/scripts/create-admin.ts`.

    **Two admin roles exist: ADMIN and SUPERADMIN.** A small number of
    the most consequential actions - suspending/reactivating/deleting a
    company, and changing country-wide pricing - require SUPERADMIN
    specifically and return 401 for a plain ADMIN. Everything else
    (approving/rejecting registrations, vehicle management, viewing
    data) is open to any authenticated admin. Each such operation below
    is marked explicitly.

    **v1.1 update**: the entire `/logistics-companies` and
    `/logistics-batches` resources were previously undocumented here
    despite being live - added in full. `DELETE
    /logistics-companies/{id}` is new. `GET /overview` gained
    `totalCompanies`. `GET /logistics-companies` list items gained
    `vehicleCount`/`completedShipments`. `Vehicle` onboarding/edit/list
    gained `companyId`, the real link used for cross-company vehicle
    scoping (see `POST /logistics-companies/.../assign` in the Company
    Portal API's own spec for where this matters most).
